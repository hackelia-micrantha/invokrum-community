# Invokrum v0.2.0

Invokrum v0.2.0 is the distribution and authenticated local-installation prerelease.

It is the first version intended to be published from `hackelia-micrantha/invokrum-community`. The historical canonical `v0.1.0` tag remains attached to its original source commit rather than being recreated from the later community baseline.

## Highlights

- Canonical `invokrum.pack-bundle/v1` identity.
- Bounded Linux directory and uncompressed POSIX ustar acquisition.
- Exact immutable-subject candidate verification.
- Strict `ed25519-subject-v1` publisher verification.
- Host-owned authorization kept separate from signature validity.
- Linux content-addressed installation with private quarantine.
- Deterministic unsigned and authenticated installation evidence.
- Explicit local install CLI for directory/archive, digest-only, and authenticated workflows.
- Independent subprocess reference-host validation.
- Public-community distribution with reviewed, allowlisted source promotion and explicit provenance.

## Security boundary

Publisher authentication proves provenance for one immutable bundle subject. It does not establish:

- host authorization unless the host's trust policy separately accepts the verified publisher;
- freshness, revocation, transparency, or rollback ordering;
- semantic prompt safety;
- runtime capability safety.

Remote acquisition and registry discovery remain outside this release.

## Supported targets

The release pipeline builds archives for:

- `x86_64-unknown-linux-gnu`;
- `x86_64-apple-darwin`;
- `x86_64-pc-windows-msvc`.

Portable operations are available across those targets. Secure local acquisition and installation remain Linux-specific.

## Verification

Download an archive and its checksum, then verify the checksum locally. For example:

```bash
sha256sum --check invokrum-v0.2.0-x86_64-unknown-linux-gnu.tar.gz.sha256
```

Verify GitHub provenance against the public repository:

```bash
gh attestation verify \
  invokrum-v0.2.0-x86_64-unknown-linux-gnu.tar.gz \
  --repo hackelia-micrantha/invokrum-community
```

The release workflow also publishes a target-specific SPDX 2.3 SBOM and SBOM attestation.

## Public source provenance

The initial community source baseline originates from canonical commit `0e6083d0608d22673b7172ce3330328c64be05bc`; `invokrum-community/UPSTREAM.md` records the baseline and repository-relocation differences. Later public changes are promoted explicitly and do not mirror private canonical history.

## Compatibility

Invokrum remains pre-1.0. Schema, bundle, lockfile, installation-evidence, CLI machine-output, host RPC, and Rust API contracts are versioned deliberately and unsupported identifiers fail closed.
