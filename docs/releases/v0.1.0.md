# Invokrum v0.1.0

Invokrum v0.1.0 is the first standalone prerelease of the deterministic prompt-overlay composition and attestation engine.

## Highlights

- Strict, bounded YAML and JSON overlay-pack parsing through `invokrum.dev/v1`.
- Deterministic profile resolution, compatibility validation, and normalized context bytes.
- Canonical manifests and `invokrum.lock/v1` evidence with structural drift verification.
- Operator CLI for validation, composition, inspection, locking, verification, and diffing.
- Read-only `invokrum.host/v1` integration facade and JSON subprocess protocol.
- Deterministic cross-platform packaging with checksums, SPDX SBOMs, provenance attestations, and SBOM attestations.
- Executable governed code-review example with byte-exact golden artifacts.

## Supported targets

The release pipeline produces archives for:

- `x86_64-unknown-linux-gnu`;
- `x86_64-apple-darwin`;
- `x86_64-pc-windows-msvc`.

Secure filesystem-backed composition and persistent output currently support Linux only. The macOS and Windows binaries support portable operations that do not require the Linux source adapter and fail closed where a native secure filesystem implementation is unavailable.

## Security boundary

Invokrum validates structure, ordering, compatibility, exact source bytes, and evidence consistency. It does not determine whether prompt content is semantically safe, grant authorization, provide a runtime sandbox, or authenticate third-party pack publishers.

GitHub build attestations bind release artifacts to the trusted release workflow. They do not authenticate overlay packs or their authors.

Remote pack fetching, plugin execution, publisher signatures, and mutable runtime dependency resolution remain outside v0.1.

## Anthesis relationship

Invokrum originated from a generic composition mechanism explored in Anthesis, but Anthesis is not required to install, run, verify, or release Invokrum v0.1. Anthesis reference-consumer conformance is deferred follow-up work and must not introduce Anthesis policy into Invokrum core.

## Verification

Download an archive and its matching checksum file, then verify locally. For example:

```bash
sha256sum --check invokrum-v0.1.0-x86_64-unknown-linux-gnu.tar.gz.sha256
```

Verify GitHub provenance against this repository:

```bash
gh attestation verify \
  invokrum-v0.1.0-x86_64-unknown-linux-gnu.tar.gz \
  --repo hackelia-micrantha/invokrum-community
```

The downloaded Linux binary should reproduce the committed artifacts under `examples/governed-code-review/` byte for byte.

## Compatibility

The schema, canonicalization, manifest, lockfile, CLI machine output, host RPC envelope, and public Rust APIs are pre-1.0 contracts. Incompatible changes will be versioned and documented, but minor pre-1.0 releases may still contain deliberate breaking changes.
